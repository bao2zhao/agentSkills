# Agent Skills Repository

这是一个用于存放常用 Agent Skill 的仓库，旨在提供一套可直接应用于日常开发流程的技能集合。

## 项目结构

```
agentSkills/
├── web/                    # Web 开发相关技能
│   ├── frontend-design     # 前端设计
│   ├── cache-components    # 前端缓存组件优化
│   ├── fullstack-developer # 全栈开发
│   ├── frontend-code-review # 前端代码审查
│   ├── code-reviewer       # 通用代码审查
│   ├── webapp-testing      # 网页应用测试
│   ├── pr-creator          # PR 创建
│   ├── fix                 # Linting 和格式修复
│   ├── update-docs         # 技术文档更新
│   └── find-skills         # Skill 查找
```

## 目录说明

### web/

存放与 Web 开发相关的技能：

| Skill 名称 | 功能描述 |
|-----------|----------|
| `frontend-design` | 创建高品质、独特风格的前端界面 |
| `cache-components` | Next.js 缓存组件最佳实践集成 |
| `fullstack-developer` | 全栈 Web 开发支持（React/Next.js/Node.js） |
| `frontend-code-review` | 前端代码自动化审查 |
| `code-reviewer` | 通用代码审查（本地变更与远程 PR） |
| `webapp-testing` | 基于 Playwright 的 Web 应用测试 |
| `pr-creator` | 自动化创建符合规范的 Pull Request |
| `fix` | 自动化修复代码格式和 linting 错误 |
| `update-docs` | 根据代码变更更新技术文档 |
| `find-skills` | 发现并安装 Agent Skill |

## 技能分类

- **前端设计**：frontend-design
- **前端开发**：cache-components
- **全栈开发**：fullstack-developer
- **代码审查**：frontend-code-review, code-reviewer
- **自动化测试**：webapp-testing
- **CI/CD**：pr-creator
- **代码质量**：fix
- **文档维护**：update-docs
- **技能管理**：find-skills

## 使用方式

每个 Skill 都包含完整的使用说明文档（SKILL.md），请查看相应目录获取详细信息。
